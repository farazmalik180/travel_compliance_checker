- **Live Hugging Face Space:** [https://huggingface.co/spaces/MF180/travel-compliance-checker](https://huggingface.co/spaces/MF180/travel-compliance-checker)

Pakistan Immigration Manager (PIM) is an AI-driven multi-agent travel compliance system that evaluates passenger profiles against official Federal Investigation Agency (FIA) departure rules and Integrated Border Management System (IBMS) guidelines to prevent wrongful offloading and ensure compliance before departure.

## Architecture (100% Free Tier)
1. **Frontend:** Hosted on **Hugging Face Spaces** (`sdk: static`) for \$0.00/month.
2. **Backend API:** Hosted on **AWS Lambda Function URL** (Always Free Tier: 1,000,000 requests/month) for \$0.00/month.
3. **Inference Engine:** Powered by **Groq** (`openai/gpt-oss-120b`).
